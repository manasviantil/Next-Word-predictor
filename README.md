](https://colab.research.google.com/github/manasviantil/Next-Word-predictor/blob/main/sentence_completion.ipynb)# Next-Word-predictor

A Machine Learning and Natural Language Processing (NLP) project that predicts the next word in a sentence using a trained deep learning model.

🚀 Features

* Predicts the next word from user input
* Trained on text dataset in CSV format
* Uses tokenization and sequence generation
* Model and tokenizer saved using Pickle (`.pkl`)
* Easy-to-use interface
* Built with Python and Deep Learning libraries
  
🛠️ Technologies Used

* Python
* Pandas
* NumPy
* TensorFlow / Keras
* Scikit-learn 
* Pickle
* Streamlit
